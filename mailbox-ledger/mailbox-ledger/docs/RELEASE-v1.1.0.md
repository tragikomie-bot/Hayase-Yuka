# 邮箱记账 1.1.0 更新通告

好啦，把账本拿过来，让我看看你最近又买了什么。该记的账可不许偷偷漏掉哦。

- 记账页加上了加减乘除计算器，支持括号，算完直接填金额。
- 工资、房租和固定开销，可以按每周几或每月几号自动记账，金额、时间和备注提前设好就行。

- 浅色、深色、跟随系统，选你喜欢的就好，熟悉的蓝色还在。

不过呀，记账不是要你什么都舍不得买。好好吃饭、照顾身体，给喜欢的事情留一点预算，这些钱都值得花。大笔开销多想一会儿，开心的小愿望也可以慢慢实现。

你的钱，最后还是由你做主。我会提醒你别乱花，也希望你舍得对自己好一点。我们一起把今天过舒服，再给明天留一点底气，好不好？
