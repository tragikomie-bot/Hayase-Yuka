# 邮箱记账 1.4.0 更新介绍

固定扣款，我记着；顺手攒下的那一点，也不会漏掉啦。💙

这次，定时记账也能用「支付宝笔笔攒」了。到“设置 → 定时记账”，新建或修改一条支出，勾选笔笔攒并保存。每次到期记下消费时，也会按保存的比例或固定金额，记下两个账本之间的攒钱转账。

- 原有定时规则默认关闭，需要的那几笔再打开即可。
- 每条定时规则保存自己的攒钱设置。想更新比例或转出、转入账本，先在设置里修改，再进入定时规则点击“使用设置中的最新攒钱规则”并保存。
- 消费和攒钱一起保存，补记和重试不会重复记录，消费也不会被重复计算。
- 从单笔记账转为定时规则时，会带上已勾选的笔笔攒规则。
- 外币所需汇率查询失败或日期不符时，整笔暂不入账，等待重试；历史账目保留保存时的金额和汇率。

你的钱还是你做主。给未来留一点，也别忘了好好照顾今天的自己。

这里只按计划记账，不连接支付宝、不核验实际扣款，也不会发起真实转账。安卓省电可能延后执行，打开应用会检查补记。实际扣款失败或金额改变时，请自行调整对应记录。

版本：1.4.0，内部版本号：6。包名和签名保持一致，可覆盖更新；建议安装前先备份账本。

## 本月定时支出汇总

设置 → 定时记账顶部新增当月汇总。统计全部账本里，记账日期属于当前月份且带定时来源的已入账支出，按原币金额分别合计。手工记录、收入、未执行计划和笔笔攒转账不计入。删除定时规则后，已经记下的支出仍按实际记录参与统计。

点击“按当天汇率查看人民币合计”才查询汇率；每种外币查询一次，人民币直接累计。结果显示查询日期、实际汇率日期和来源。休市返回非当天参考汇率会明确提示；部分币种失败时不显示不完整的总额。折算仅供查看，不更改账目或历史汇率。

按手机本地月份自动切换，下个月统计下个月；重新打开、回到前台或停留页面时跨月都会更新。版本沿用1.4.0，其他功能保持原样。
