# 邮箱记账 v1.0.0

邮箱记账的首个发布版本，采用角色图标与蓝色主题，帮助你按日历记录日常收支。

## 主要功能

- 多账本独立管理，自选账本统计币种。
- 日历首页区分已记账与未记账日期，展示当月收入、支出和结余。
- 支持收入、支出、分类、备注，以及记录的修改与删除。
- 自动外币折算、历史汇率查询、手动汇率和两种货币之间的独立换算。
- 保留每笔记录的原币金额、汇率与换算结果。
- 图标背景蓝色主题，白色/黑色界面随系统主题切换。
- 本地保存、JSON 备份与恢复，无登录、无广告，不依赖 Google 服务。

## 安装

下载本次 Release 附带的 `mailbox-ledger-1.0.0.apk`。支持 Android 8.0 及以上，需较新的系统 WebView。

自动汇率功能需要在“设置”中填写自行申请的极速数据 AppKey，然后测试连接。同币种记账无需配置接口即可使用。

版本：1.0.0；包名：cn.qinglan.ledger。已通过界面测试和 APK 签名校验，尚未完成实体手机和真实汇率账号验证。
