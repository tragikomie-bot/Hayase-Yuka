# 邮箱记账 1.3.0 更新通告

好啦，这次把你说的笔笔攒也记进账本里了。花一笔，顺手给未来留一点，咱们慢慢来。

- 设置新增支付宝余额宝笔笔攒规则，比例支持1%、5%、10%、20%、30%、50%、80%、100%。先算比例，再向上补到最近的 .88，恰好等于不进位，最高99.88元。
- 固定攒可以填写每笔金额，不补尾数、不套用比例攒上限。
- 直接选择已有的转出账本、转入账本。攒下的钱从一个账本转到另一个账本，两边日历、明细和结余同步更新。
- 记支出时勾选支付宝笔笔攒，预览后和消费一起保存。日历加减金额包含转账，月收入、月支出单独统计消费收支，不重复算花销。
- 改金额同步重算、取消勾选或删除消费同步移除攒钱记录。更改全局规则不改旧账，编辑旧账可主动改用最新规则。

你的钱由你做主，攒下一点底气，也别忘记对自己好一点。

此功能按用户自定义规则记录，不是支付宝官方算法声明，不连接支付宝，不实际扣款。账本统计只是本应用记录，不是银行或支付宝真实余额。当前只随手工勾选的支出生成，定时规则不会自动附带笔笔攒。

人民币消费直接计算；外币消费在人民币账本中使用已保存的人民币折算金额。在外币账本中，可以填写实际人民币消费金额，或点击“按记账日期汇率填入”，旧日期参考汇率需确认。攒钱规则按人民币计算，再分别换算到账本币种。转账汇率可自动查询或手动填写，保存后保持不变。

备份包含账本、规则及关联转账，恢复校验金额、汇率和账本引用。旧版独立账户记录保留但不会自动计入账本；请先保存账本规则，再修改旧消费并点击“改用设置中的最新规则”完成关联。包名和签名保持不变，versionName=1.3.0、versionCode=5。建议先导出账本备份再覆盖安装，不需卸载。
