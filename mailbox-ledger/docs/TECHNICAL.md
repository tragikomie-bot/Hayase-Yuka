# 邮箱记账 1.0.0

采用图标背景蓝色（#4987EE）与白色/黑色的安卓本地记账应用，包名 `cn.qinglan.ledger`。Android 8.0 及以上，需较新的 Android System WebView（支持 BigInt 和现代 JavaScript）。无 Google 服务依赖，无广告和登录。

## 使用

1. 安装 APK 后，默认进入当月日历与“日常账本”。浅蓝日期表示有记账，空白表示未记账，细框标记今天，深蓝表示选中的日期。日期下的点表示支出或收入。
2. 点“＋”添加收入/支出，填写金额、币种、日期、分类和备注。点已存记录可修改或删除。
3. 在“账本”创建独立账本，并选择统计币种（默认人民币）。不同原币金额自动换算至该账本的统计币种；已有账本的币种固定，避免旧账混用单位。
4. 在“设置”填写**极速数据的 AppKey**。需自行注册并开通“汇率查询”：https://www.jisuapi.com/api/exchange/ 。这不是 DeepSeek API Key。官方页面在开发时显示免费会员100次/天，具体权限和额度以你的账户为准。
5. 点“保存设置”和“测试连接”。国内接口已接入，无需配置代理，但实际网络和服务可用性仍取决于运营商、服务商和账号。未设置密钥时，同币种记账可离线使用；外币可以手动录入实际汇率。
6. “货币换算”可单独转换任意两种服务商支持的货币。列表外可输入三位货币代码；服务商不支持的币种会报错。
7. “设置→导出全部账本”保存 JSON 备份；“从备份恢复”替换全部账本，会先要求确认。备份不含密钥。卸载会删除本机账目，卸载前请备份。

## 汇率行为

- 今日记录：查询最新可用汇率 `/exchange/convert`，请求 amount 固定为1，真实金额在本地计算。
- 补记旧账：查询所选日期的 `/exchange/history`。无数据或无权限时明确报错，可手动填写，不冒用今日汇率。
- 未来日期：没有可查询的汇率，允许手动填写。
- 默认复用同币种对、同日期的当天汇率；可关闭缓存改为每次打开新的外币记账查询。表单上还可“重新查询汇率”。历史记录修改金额/备注时保留原有汇率，修改币种/日期才重新查询。
- 保存每笔原币金额、目标金额、汇率、来源和更新时间。旧账金额不随新汇率变动。
- 若返回的汇率日期与记账日期不同（例如休市），必须勾选确认后才可保存。没有汇率时不会按1:1或假设值记账。
- 金额最多2位小数，汇率最多18位小数。使用整数十进制算法与四舍五入，避免浮点金额误差。目标金额统一保留2位小数。
- 本软件记录收支和参考换算，不执行真实货币兑换或账户转账。实际银行卡扣款/到账可手动录入对应汇率。

## 数据与隐私

账目在应用私有目录中以 AtomicFile 原子写入，失败不会覆盖旧账。AppKey 通过 Android Keystore AES-GCM 加密，仅保存在本机。应用仅申请联网权限。界面静态文件均在 APK 内；WebView 阻止外部页面和资源访问。账目/备注不发送给汇率平台。需要联网时仅向 `api.jisuapi.com` 发送 AppKey、币种、查询日期及数量1。Android 自动云备份已禁用。

## 构建

在 Linux x86_64 下安装 Java 17+、curl、unzip、Python 3，运行：

```bash
./build.sh
```

脚本从 Android 官方下载 API 35 平台和 Build Tools 35，从 Maven Central 下载 Eclipse ECJ 编译器，不需要 Gradle；输出 `output/mailbox-ledger-1.0.0.apk`。构建工具可通过 `QINGLAN_SDK` 和 `QINGLAN_ECJ` 指定。

公开源码包不包含 signing/ 签名材料。第一次构建会在本机自动生成签名文件，后续应保留这些文件。自行生成的签名不能覆盖安装作者签名的 APK；要发布可覆盖升级的作者版本，应在本机使用原来的签名材料，且不要提交签名文件或密码。

## 测试

- `node tests/money.test.cjs`：精确金额、小数舍入、负数/无效输入、超大累计金额。
- `tests/ui.test.cjs`：使用 Playwright 与模拟 Android 桥、模拟汇率响应验证界面交互。安装 playwright 后指定 CHROME_BIN 与 SHOT_DIR 执行。
- APK 通过 ECJ / D8 编译、aapt2 资源链接、zipalign 对齐与 apksigner 签名验证。
- 无有效用户 AppKey，因此未完成真实账号的付费/免费汇率端到端调用；也未在实体安卓手机安装实测。测试截图中的交易和汇率均为测试数据，安装包初始账本为空。

接口依据：极速数据官方汇率转换/历史汇率文档 https://www.jisuapi.com/api/exchange/ 。
