# 邮箱记账 1.5.1 更新介绍

把源码、说明和版本号一起整理到 1.5.1，方便覆盖安装与发布。💙

这次是在 1.5.0 基础上的版本同步更新：应用内版本号、构建产物名和仓库文档已对齐为 **1.5.1**（内部 versionCode **7**）。功能沿用当前源码包中的实现，包括多账本、定时记账、支付宝笔笔攒、本月定时支出汇总，以及国内/国外汇率来源。

- 外币自动汇率失败时会保留待处理并重试；备份恢复后定时规则默认暂停。
