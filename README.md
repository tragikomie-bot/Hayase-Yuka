邮箱记账是一款轻量的安卓本地记账应用。以当月日历为首页，清楚区分已记账和未记账的日期，用蓝色与随系统切换的白色/黑色界面记录每天的收支。

## 功能

- **多个账本**：日常、旅行、家庭等账目独立管理，每个账本可以设置自己的统计币种。
- **日历首页**：查看当月收支和结余，日期直接显示 +收入/−支出，点击查看或补记当天记录。
- **备注与分类**：每笔收入、支出均可添加备注和分类，支持修改与删除。
- **外币自动折算**：按所选日期获取参考汇率，折算为账本币种，并保留原币金额、汇率和换算结果。
- **双向货币换算**：支持人民币与外币，或服务商支持的任意两种货币之间的换算。
- **三种主题**：主色为图标背景蓝色 `#4987EE`，浅色模式使用白色界面，深色模式使用黑色界面；可手选浅色/深色或跟随系统。
- **本地保存与备份**：无需登录，无广告，不依赖 Google 服务，支持全部账本的 JSON 导出和恢复。

- **记账计算器**：支持加减乘除、括号，结果直接填入金额。
- **定时记账**：每周几/每月几号自动记账，支持执行时间、备注、外币规则与暂停管理。月底缺日按月末处理，后台延迟后打开应用补记。

## 下载与安装

在本仓库的 **Releases** 页面下载 `mailbox-ledger-1.3.0.apk`，通过安卓系统安装器安装。

- Android 8.0 及以上，需较新的 Android System WebView。
- 同一签名的版本可覆盖安装；卸载会删除本机账目，卸载前请导出备份。
- 当前应用版本为 `1.3.0`，包名保持 `cn.qinglan.ledger`。

## 配置自动汇率

1. 在 [极速数据](https://www.jisuapi.com/api/exchange/) 注册并申请“汇率查询”接口。
2. 打开应用 **设置 → 自动汇率**，填入该服务的 **AppKey**。
3. 保存设置，点击“测试连接”。

同币种记账可离线使用，无需 AppKey。外币记账可以查询汇率，也可以手动填写实际汇率。接口额度、币种范围和历史查询权限以服务商账户为准。未获取有效汇率时，应用会给出提示，不会填入猜测值。

默认复用同币种对、同日期的汇率以减少请求；关闭“复用当天汇率”后，新建外币记录时联网查询。接口返回的汇率日期若与记账日期不同，需要确认后才能保存。已保存记录不会随之后的汇率变动而改变。

## 隐私

账目和备注保存在本机，AppKey 使用 Android Keystore 加密保存。汇率查询仅向极速数据发送必要的密钥、币种、日期及固定数量1，不发送真实记账金额或备注。应用申请联网和开机接收权限，后者用于恢复定时规则。备份文件不包含 AppKey。

## 从源码构建

构建环境：**Linux x86_64、Java 17+、curl、unzip、Python 3**。

```bash
bash build.sh
```

脚本会下载 Android API 35、Build Tools 35 和 Eclipse ECJ，使用 ECJ、D8、aapt2、zipalign、apksigner 编译并签名，无需 Gradle。产物位于：

```text
output/mailbox-ledger-1.3.0.apk
```

此公开源码包**不含原始签名私钥和密码**。首次自行构建会生成本机签名，自行签名的 APK 无法覆盖安装作者签名的 APK。发布后续覆盖更新时，应在本机沿用最初的签名材料，且保持这些文件不进入公开仓库。

## 笔笔攒
设置 → 支付宝余额宝笔笔攒：选择比例或固定金额、转出账本、转入账本后保存。在记支出页面勾选使用。转账不重复计入消费，不会实际扣款。详见 RELEASE-v1.3.0.md。

### 同版本账本转账修订

直接选择已有账本，两边日历与结余包含转账，消费收支不重复计入。外币账本支持查询或手动转账汇率并冻结保存。旧版独立账户记录保留；先配置账本规则，再编辑旧消费并主动选择“改用设置中的最新规则”可完成关联。版本保持1.3.0/5。
